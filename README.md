# The Poem About Stopping

A short poem about agency: the power to stop and to stay. A thumb lifts
from the send button; a door is left unlocked, not unguarded; staying
turns out to be a choice, not a failure to move.

Competition: [The poem about stopping](https://make.fun/bounty/the-poem-about-stopping-20261121-1927)

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt`.

## Determinism

The poem is a fixed constant in `main.py`. There is no input, no
randomness, no network access, and no use of the clock, so every run
produces byte-identical output.
